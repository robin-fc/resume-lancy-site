# AI 简历助手 (resume.lancy.site)

基于 Magic Resume 思路改造的 AI 简历助手网站，提供简历结构化编辑、JD 关键词分析、AI 改写建议、ATS 检查清单与模板预览。

## 功能

- **简历诊断**：根据目标岗位描述提取关键词，计算简历匹配度。
- **AI 改写建议**：将经历改写成“动作 + 指标 + 结果”的招聘友好表达。
- **ATS 清单**：检查邮箱、电话、量化结果、关键词覆盖等基础项。
- **模板预览**：提供单页简历预览结构，后续可接入 PDF 导出。

## 开发

```bash
npm install
npm run dev
```
